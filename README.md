# Realistic VR Horse Racing & Riding Simulator

A realistic VR horse riding and racing simulator project developed with Unity 3D and C#, fully compatible with the Meta Quest ecosystem.

### 🚀 Key Features / Core Systems (WIP)
- **Custom VR Horse Controller:** Realistic equestrian and horse control mechanics integrated with XR Interaction Toolkit.
- **NavMesh & Waypoint AI:** Smart pathfinding system for competitor AI horses using NavMesh and waypoint navigation.
- **Race Manager:** Modular C# architecture handling race states, finish line detection, and lap management.

### 🛠️ Tech Stack & Tools
- **Game Engine:** Unity 3D
- **Language:** C#
- **VR SDK:** XR Interaction Toolkit / OpenXR
